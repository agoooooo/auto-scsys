# FlowPilot 产品 Demo

这是一个纯前端交互原型，使用内置模拟数据，不连接真实服务端。可以在管理后台与 Android 手机端视图之间切换，体验用户、设备、任务发布和任务运行流程。

## 运行

在仓库根目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/docs/demo/>。原型不需要安装依赖。

## 可体验的操作

- 管理后台：浏览总览、搜索用户、创建用户、停用/启用用户、管理设备、发布任务版本、查看运行记录。
- 手机 App：查看任务、模拟运行已发布任务、管理绑定设备、查看最近运行结果。
- 所有更改只保存在当前页面内存中，刷新后恢复为初始演示数据；不会触发真实设备操作或后端请求。
