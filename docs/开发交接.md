## 项目现状

FlowPilot 已打通 Android 用户登录/设备绑定、脚本发布和授权、设备端 Python 执行及远程任务派发。生产 Web 管理后台使用独立 React/TypeScript/Vite 工程、Ant Design 和 Monaco Editor；旧 `demo/` 原生 JavaScript 只留作回归参考，不参与部署。FastAPI 提供服务端鉴权/API，Nginx 提供静态控制台并代理 `/api/*`；开发时 Vite 提供同路径代理。控制台不提供离线演示/模拟成功模式，可用管理员账号管理用户、设备、任务、脚本不可变版本、运行记录及审计；任务页支持直接编写 Python 源码、浏览版本源码、SHA-256 校验发布及版本切换。脚本只在获授权受控设备上运行，不在浏览器/API 服务执行。此后台实现不代表服务已具备全部生产安全和运维保障。

**产品范围决策（2026-10-14）：** 本期 Web 下一步不是新增独立用户门户，而是在现有控制台中提供普通用户工作区，并同时适配手机浏览器、平板和桌面。普通用户应能管理自己的设备，创建个人任务/脚本，使用 Monaco 编写脚本并自动保存/恢复服务端草稿，查看版本差异、发布不可变版本或切回旧版本，选择自己有权操作的在线设备运行/停止任务并查看历史。管理员仍使用原有全局管理工作区。所有用户数据在 API 侧按账号、角色和资源所有权隔离；隐藏管理员菜单不视为访问控制。移动端须能完整完成这些主要流程，而非只读页面；表格、导航、表单、编辑器和确认弹窗均须适配窄屏与触控。暂不实现多人协作、脚本市场、审批和定时任务。

### 需求更新（2026-10-13）

目标产品形态明确为“控制端 + 受控端”两个分开的 Android 客户端：控制端 Android App（Web 后台仍保留）负责管理设备及下发/跟踪/停止任务；受控端 Android App 独立负责绑定执行设备、接收指令、运行脚本并反馈状态。Web 和控制端 App 共用服务端 API 和设备授权规则。独立 `:controller` Android 模块已交付 MVP，并完成 REDMI Android 14 真机的控制端派发、受控端执行、停止请求及 `stopped` 终态回传闭环；控制端和受控端均有角色化帮助/关于入口。不应将受控端改成双模式来代替独立控制端。

控制端 MVP 使用包名 `com.flowpilot.controller`，支持普通用户注册/登录、在线设备优先展示、多选在线设备和已发布脚本并批量派发、逐项查看队列/运行状态、取消排队请求及请求停止运行中的任务。服务端以设备锁串行维护每台设备的待派队列；同一设备一次只向受控端提供队首请求，运行完成、拒绝或过期后再激活下一项，队列不依赖控制端进程存活。设备级运行互斥仍由服务端唯一部分索引保证。服务端以幂等标记记录停止请求，受控端每 5 秒检查一次，并在脚本下一个停止检查点响应；不承诺强制中断任意阻塞代码。受控端不承担控制 UI，控制端不包含受控执行运行时。用户明确本阶段不需要脚本安全边界功能；仍需遵守 Android 自身的系统权限流程和常规账号、设备授权。

用户补充客户端需支持自助注册及常用 App 账号体验。普通用户使用姓名、邮箱和至少 6 位密码注册，不强制邮箱验证；管理员账号不可自助注册。普通用户 `/auth/register` API 和 Android 注册入口已实现，注册后需返回登录页登录。个人资料编辑和登录后改密 API 已实现，邮箱修改须当前密码确认；改密后撤销其他会话并保留当前会话。Web 支持标签页会话和可选的本机记住登录，并会自动续期短期访问令牌；Android 控制端使用加密会话存储并自动续期。邮件验证码找回 API 及三个客户端入口均已实现；只有 SMTP 配置完整时服务端能力探测才显示入口。实际 SMTP 服务尚未配置和验收。

本地开发使用 SQLite 和演示数据。最终生产入口配置使用 PostgreSQL、MinIO/S3 兼容存储、Caddy HTTPS、静态 Web 和 FastAPI。按当前项目决策，公网域名及 HTTPS 推迟到最后上线阶段；当前应先在隔离的开发/预生产环境开发和验证数据库、对象存储及业务流程。`compose.staging.yaml` 已新增 loopback-only 默认的 HTTP 预生产配置；现有 production Compose profile 强制域名和 HTTPS CORS，不能替代它。

## 已完成开发

- **服务端：** FastAPI 认证与服务端会话、角色及资源授权、用户/设备/任务/版本/授权/运行记录管理、设备心跳、审计、运行请求有效期和终态查询。远程请求由设备轮询，服务端验证目标用户、在线设备、任务版本、设备空闲和授权后允许 App 执行。
- **脚本交付：** 开发 SQLite 流程保留 API 上传/下载兼容路径；生产对象存储路径使用短时预签名上传/下载地址。上传完成时服务端复核大小和 SHA-256；设备下载后也会校验哈希。对象桶不公开。
- **Web 控制台：** 管理用户、设备、任务及版本，授权/发布脚本，查看运行和审计记录；普通用户可向自己名下在线设备发起任务。离线演示状态不能真实派发；提交前再次校验设备归属和在线状态；Web 会轮询远程请求并展示排队、运行和终态摘要。
- **生产 Web 管理后台（现状）：** 新增 React/TypeScript/Vite + Ant Design 管理控制台、同源 Monaco Python 编辑器/worker、受权限保护的源码读取 API、不可变版本发布/切换/差异比较和构建部署接线。当前页面实现管理员登录校验、总览、用户/设备/任务/运行/审计列表及核心维护操作；Vite build、API/前端回归、生产容器、Nginx 配置与静态/SPA 路由已通过验证。任务草稿目前只在当前浏览器标签页临时保存。
- **普通用户 Web 工作台（已决策、待开发）：** 共用当前 React 控制台，不另建门户。增加角色化导航及普通用户的个人设备、任务/脚本、服务端草稿、版本比较/发布/回切、远程运行/历史页面；补全列表和详情的所有权授权测试、草稿自动保存/恢复/冲突提示及真实浏览器端到端验收。工作台与现有管理员页面都要适配手机/平板：移动导航、窄屏数据呈现、触控操作和 Monaco 小屏编辑均须可用。不得把上述目标描述为已实现。管理员 MFA、入口/API 限流、正式 CSP/安全评审、跨浏览器 E2E 与真实生产域名验收仍未完成。
- **Android 受控端：** 原生 Kotlin/Compose 客户端、设备绑定与心跳、脚本缓存及校验、Chaquopy Python 运行时、桥接接口、运行历史、停止入口，以及远程运行待命服务。登录后通过底部“设备 / 任务 / 运行 / 我的”导航查看设备状态、自动同步的任务、运行请求/历史及账号设置。运行页显示最近 10 条服务端历史，点击卡片打开详情（任务、状态、版本、设备、起止时间、结果、运行 ID 和可用时的远程请求 ID）；已结束任务不再单独显示“最近一次运行”卡片，仅活动中的本地任务显示为“当前任务”并保留停止操作。设备权限、自动启动及系统授权说明见 [`../android/README.md`](../android/README.md)。
- **Android 控制端：** 独立 `android/controller` 应用，包名 `com.flowpilot.controller`。支持普通用户登录、在线设备优先/分组展示、选择设备和已发布脚本批量派发、同设备服务端持久队列、跟踪/取消/停止请求；不承担脚本执行。在线设备组默认展开，离线设备组默认折叠，已停用设备不展示；离线设备可逐台确认解绑，解绑由服务端停用设备并撤销待处理请求、设备授权和分发记录，但不保证中止已开始的本地任务。运行页打开或手动刷新时读取最近 10 条执行历史，点击卡片查看任务、状态、版本、设备、起止时间、结果和运行标识详情。“最近一次运行”已移除；活动请求仍以“当前任务状态”显示取消/停止入口。设备卡片、账号页和运行页的详细行为见 [`../android/controller/README.md`](../android/controller/README.md) 与 [`../android/README.md`](../android/README.md)。
- **客户端账号体验：** 普通用户自助注册 API 与 Android 注册界面已实现，首版不强制邮箱验证且只创建普通用户；当前用户可编辑资料（邮箱修改须当前密码）、登录后修改密码（撤销其他会话，当前会话保留）。Web 默认使用标签页存储，可选择记住登录；Android 控制端加密保存会话。Web/Android 自动续期访问令牌并在服务端会话失效时提示重新登录。邮件服务未配置前不开放密码找回。
- **密码找回：** 服务端提供 SMTP 可选配置、通用忘记密码响应、HMAC 摘要验证码存储、10 分钟过期、邮箱/IP 限流、5 次错误尝试锁定、邮件发送失败时作废验证码，以及成功重置后撤销所有会话并记审计。Web、控制端 Android 和受控端 Android 登录页均已接入能力探测和找回表单；SMTP 缺失时 UI 隐藏且 API 返回 `503`。实际 SMTP 服务仍待运维配置和投递验收。
- **OCR 演示：** 订单状态脚本打开抖音/抖音极速版，在设备本地等待和 OCR；不点击、不上传 OCR 文本。上传到服务端的执行摘要是白名单安全摘要，不包含任意 Python 异常或屏幕内容。
- **运维基础：** 提供 loopback-only 默认的私有 HTTP 预生产 Compose（PostgreSQL、RustFS S3 兼容后端、API、Web），以及 PostgreSQL、MinIO、API、Web、Caddy HTTPS 最终部署配置；PostgreSQL 备份工具可生成归档并校验、独立验证已有归档的 SHA-256 和格式。仓库已有部署和恢复说明，但脚本不会替运维人员配置加密异地存储、调度器和告警。
- **Android 品牌与布局：** 已更新 FlowPilot 原生界面、状态徽标和桌面图标。
