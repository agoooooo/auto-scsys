## 项目现状

FlowPilot 已打通 Android 用户登录/设备绑定、脚本发布和授权、设备端 Python 执行、Web 管理及远程任务派发。当前不是 React/Vite 前端：实际 Web 控制台是 `demo/` 下的原生 JavaScript ES modules，由静态文件服务器/Nginx 提供；API 为 FastAPI；Android 客户端使用 Kotlin、Jetpack Compose 与 Chaquopy。

### 需求更新（2026-10-13）

目标产品形态明确为“控制端 + 受控端”两个分开的 Android 客户端：控制端 Android App（Web 后台仍保留）负责管理设备及下发/跟踪/停止任务；受控端 Android App 独立负责绑定执行设备、接收指令、运行脚本并反馈状态。Web 和控制端 App 共用服务端 API 和设备授权规则。独立 `:controller` Android 模块已交付 MVP，并完成 REDMI Android 14 真机的控制端派发、受控端执行、停止请求及 `stopped` 终态回传闭环；控制端和受控端均有角色化帮助/关于入口。不应将受控端改成双模式来代替独立控制端。

控制端 MVP 使用包名 `com.flowpilot.controller`，支持普通用户注册/登录、查看设备与已发布任务、向在线设备派发并轮询运行状态、取消等待请求及请求停止运行中的任务。服务端以幂等标记记录停止请求，受控端每 5 秒检查一次，并在脚本下一个停止检查点响应；不承诺强制中断任意阻塞代码。远程派发使用 `Idempotency-Key` 防止网络重试重复创建请求；以目标设备锁和数据库唯一部分索引保证 Web、控制端、受控端之间单设备互斥。以上停止闭环和真机结果上报已在 REDMI Android 14 验证，Web 真实派发另有独立端到端验证。受控端不承担控制 UI，控制端不包含受控执行运行时。用户明确本阶段不需要脚本安全边界功能；仍需遵守 Android 自身的系统权限流程和常规账号、设备授权。

用户补充客户端需支持自助注册及常用 App 账号体验。首版普通用户使用姓名、邮箱和至少 12 位密码注册，不强制邮箱验证；管理员账号不可自助注册。普通用户 `/auth/register` API 和 Android 注册入口已实现，注册后需返回登录页登录。个人资料编辑和登录后改密 API 已实现，邮箱修改须当前密码确认；改密后撤销其他会话并保留当前会话。Web 支持标签页会话和可选的本机记住登录，并会自动续期短期访问令牌；Android 控制端使用加密会话存储并自动续期。邮件密码找回依赖邮件服务，配置前不开放该入口。

本地开发使用 SQLite 和演示数据。最终生产入口配置使用 PostgreSQL、MinIO/S3 兼容存储、Caddy HTTPS、静态 Web 和 FastAPI。按当前项目决策，公网域名及 HTTPS 推迟到最后上线阶段；当前应先在隔离的开发/预生产环境开发和验证数据库、对象存储及业务流程。`compose.staging.yaml` 已新增 loopback-only 默认的 HTTP 预生产配置；现有 production Compose profile 强制域名和 HTTPS CORS，不能替代它。

## 已完成开发

- **服务端：** FastAPI 认证与服务端会话、角色及资源授权、用户/设备/任务/版本/授权/运行记录管理、设备心跳、审计、运行请求有效期和终态查询。远程请求由设备轮询，服务端验证目标用户、在线设备、任务版本、设备空闲和授权后允许 App 执行。
- **脚本交付：** 开发 SQLite 流程保留 API 上传/下载兼容路径；生产对象存储路径使用短时预签名上传/下载地址。上传完成时服务端复核大小和 SHA-256；设备下载后也会校验哈希。对象桶不公开。
- **Web 控制台：** 管理用户、设备、任务及版本，授权/发布脚本，查看运行和审计记录；普通用户可向自己名下在线设备发起任务。离线演示状态不能真实派发；提交前再次校验设备归属和在线状态；Web 会轮询远程请求并展示排队、运行和终态摘要。
- **Android 受控端：** 原生 Kotlin/Compose 客户端、设备绑定与心跳、脚本缓存及校验、Chaquopy Python 运行时、桥接接口、运行历史、停止入口，以及远程运行待命服务。远程请求服务端校验通过后可自动启动，无需逐任务确认；系统屏幕捕获、通知和无障碍权限仍由用户按 Android 流程授予。
- **Android 控制端：** 独立 `android/controller` 应用，包名 `com.flowpilot.controller`。MVP 已支持普通用户注册/登录、设备与已发布任务列表、在线设备远程派发、取消等待请求、请求停止运行中任务及运行状态轮询；不承担脚本执行。重开 App 后可恢复所选设备当前的等待/运行中请求，但不保证退出页面后的后台跟踪。
- **客户端账号体验：** 普通用户自助注册 API 与 Android 注册界面已实现，首版不强制邮箱验证且只创建普通用户；当前用户可编辑资料（邮箱修改须当前密码）、登录后修改密码（撤销其他会话，当前会话保留）。Web 默认使用标签页存储，可选择记住登录；Android 控制端加密保存会话。Web/Android 自动续期访问令牌并在服务端会话失效时提示重新登录。邮件服务未配置前不开放密码找回。
- **OCR 演示：** 订单状态脚本打开抖音/抖音极速版，在设备本地等待和 OCR；不点击、不上传 OCR 文本。上传到服务端的执行摘要是白名单安全摘要，不包含任意 Python 异常或屏幕内容。
- **运维基础：** 提供 loopback-only 默认的私有 HTTP 预生产 Compose（PostgreSQL、RustFS S3 兼容后端、API、Web），以及 PostgreSQL、MinIO、API、Web、Caddy HTTPS 最终部署配置；提供 PostgreSQL 备份脚本及校验。仓库已有部署和恢复说明，但脚本不会替运维人员配置加密异地存储、调度器和告警。
- **Android 品牌与布局：** 已更新 FlowPilot 原生界面、状态徽标和桌面图标。

## 最近排查和端到端验证

2026-10-13 在 Firefox 中打开 `http://localhost:8000/demo/?deviceId=...`，以普通用户通过真实 Web 登录，并从任务卡打开“订单状态检查”运行弹窗。Web 自动选择在线 Redmi，实际发出：

```text

POST http://localhost:8001/remote-runs                     -> 201
GET  http://localhost:8001/remote-runs/{request_id}        -> 200
```

发现并修复了派发按钮此前不工作的根因：`revoke-user-sessions` 的点击处理分支被误放在全局表单提交监听器中。提交事件执行到该分支时读取未定义的 `action`，监听器异常退出且未阻止浏览器默认提交，页面被重新加载，远程运行 POST 因而没有发生。现已将该处理移回点击监听器，并增加回归测试。

修复后 Web 发起的真实设备请求成功：

- 设备：Redmi（测试机 `192.168.0.104:5555`），App 绑定 ID `d0ed9814-4814-4221-bdb6-97de68e34583`。
- 任务：`订单状态检查`，版本 `v1.7.0`。
- 远程请求 ID：`4c68ce03-6840-4b5d-ab85-328f3d9f5bc0`。
- 运行 ID：`7de89791-6599-49c9-8e06-e2d1ef39a1a0`。
- 结果：服务端终态 `success`，摘要 `任务完成`。

另外曾直接测试 HTTPS 控制台 API 默认值错误：HTTPS 页面原先会默认访问 `http://<Web 主机>:8001`，可能因混合内容或错误主机导致请求失败。现已改为默认同源 `/api`，Caddy 在 Web 域名上将 `/api/*` 转发给 API；本地 HTTP 开发仍默认 `http://<主机>:8001`。

## 未完成 / 已知限制

1. **当前阶段：生产 PostgreSQL/S3 与运维恢复就绪度。** `compose.staging.yaml` 提供 loopback-only 默认的应用、PostgreSQL 和 RustFS S3 兼容测试栈；预签名上传/下载链路、CORS、PostgreSQL 行锁并发行为及临时数据库/对象的隔离恢复已在 staging 验证。仍需针对最终生产 MinIO/S3 后端另行验收；加密异地备份目标、调度/告警配置和生产类独立恢复环境仍待运维侧提供。不得对公网开放 HTTP 服务或使用真实生产凭据。
2. **备份可观测性受运维配置阻塞：** 仓库备份工具会生成并校验 PostgreSQL 归档与 SHA-256，但加密、异地复制、保留周期、定时调度、失败告警及 MinIO 对象备份须由部署环境配置。
3. **最后上线阶段：公网域名与 HTTPS。** 按项目决策明确推迟，不是当前开发前置条件；对外开放 Web/API 或分发 Release APK 前必须完成，并校验 HTTPS、CORS、对象存储 URL 与 Android 配置。
4. **Android 后台能力受系统约束：** App 不能静默授予 MediaProjection 或无障碍权限；OCR 待命和远程执行需要用户按系统要求授权并保留可见通知。系统/厂商可能回收进程，不能承诺永久后台在线。
5. **自动化场景有限：** 当前演示针对抖音和抖音极速版，仅本机 OCR 常见订单状态，不点击、不上传屏幕/OCR 内容；不等同于通用手机自动化。
6. **Web→Android 真机链路已验证通过：** 最近 Firefox Web UI 的真实请求已成功执行。若其他浏览器/部署仍不派发，需核对该页面登录账号角色、服务端 API 地址、所选设备 ID 尾缀、浏览器网络面板的 `/remote-runs` 响应，以及 Android 远程待命状态；不要把旧设备注册 ID 的请求误认为当前绑定设备。
