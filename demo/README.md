# FlowPilot 产品 Demo

这是一个可连接本地 API 的浏览器原型，也保留离线演示模式。可以在管理后台与 Android 手机端视图之间切换，体验用户、设备、任务发布、暂停和任务运行流程。

## 运行

在仓库根目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/demo/>。原型不需要安装依赖。

FastAPI 服务端可按 [`server/README.md`](../server/README.md) 单独运行，也可在仓库根目录用 `make dev` 同时启动。LAN 访问时，登录界面会默认将当前页面主机名配合 API 端口 `8001` 作为服务端地址；也可以选择“仅浏览离线演示”。

## 可体验的操作

- 管理后台：浏览总览、搜索/筛选/分页查看用户、创建用户、导出筛选后的用户 CSV、调整设备数量上限、停用/启用用户、管理设备、发布脚本版本并切换当前版本、管理任务访问授权、暂停/恢复任务、向在线设备发起远程运行请求、按状态/关键词筛选和导出 CSV 运行记录、查看管理员操作审计。
- 手机 App：查看任务来源和能力说明、确认或拒绝远程请求、按具体设备和版本设置/撤销 30 天预授权、查看前台运行状态并停止任务、模拟 OCR 结果。
- 离线演示状态只保存在页面内存中，刷新后恢复为初始演示数据。连接 API 后，用户、设备、脚本和运行记录由本地服务端保存。

## 产品边界

浏览器原型不会运行真实设备操作或 Python 代码。API 已加入本地 SQLite 开发存储，上传的脚本由 API 保存并计算 SHA-256，但仍不执行；本地服务尚未适配生产 PostgreSQL/S3。演示中的 OCR 结果和运行记录仍是模拟流程。真实 Android 版本仍需在系统授权与可见前台执行限制下实现。

运行状态逻辑的单元测试可通过 `node --test demo/state.test.mjs` 执行。
