# FlowPilot 产品 Demo

这是一个纯前端交互原型，使用内置模拟数据，不连接真实服务端。可以在管理后台与 Android 手机端视图之间切换，体验用户、设备、任务发布和任务运行流程。

## 运行

在仓库根目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/demo/>。原型不需要安装依赖。

## 可体验的操作

- 管理后台：浏览总览、搜索用户、创建用户、停用/启用用户、管理设备、选择 Python 脚本版本并校验 SHA-256、向自己的在线设备发起远程运行请求、查看运行记录。
- 手机 App：查看任务来源和能力说明、确认或拒绝远程请求、按具体设备和版本设置/撤销 30 天预授权、查看前台运行状态并停止任务、模拟 OCR 结果。
- 所有更改只保存在当前页面内存中，刷新后恢复为初始演示数据；不会触发真实设备操作或后端请求。

## 产品边界

此仓库目前交付的是浏览器交互原型，不包含 Android 原生应用、真实 Python 运行时、认证/API、持久化数据库或对象存储。选择的 `.py` 文件只在浏览器中计算哈希，不会上传或保存脚本内容。演示中的确认、预授权、OCR 结果和运行记录仅用于展示产品流程；预授权严格绑定单个设备和脚本版本，新版本不会继承。真实版本仍需在 Android 系统授权与可见前台执行限制下实现。

运行状态逻辑的单元测试可通过 `node --test demo/state.test.mjs` 执行。
