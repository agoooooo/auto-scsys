# FlowPilot 产品 Demo

这是一个可连接本地 API 的浏览器原型，也保留离线演示模式。可以在管理后台与 Android 手机端视图之间切换，体验用户、设备、任务发布、暂停和任务运行流程。

## 运行

在仓库根目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/demo/>。原型不需要安装依赖。

FastAPI 服务端可按 [`server/README.md`](../server/README.md) 单独运行，也可在仓库根目录用 `make dev` 同时启动。LAN 访问时，登录界面会默认将当前页面主机名配合 API 端口 `8001` 作为服务端地址；也可以选择“仅浏览离线演示”。

## 可体验的操作

- 管理后台：浏览总览、搜索/筛选/分页查看用户、创建用户、导出筛选后的用户 CSV、调整设备数量上限、停用/启用用户、按状态筛选并分页查看设备、搜索/筛选/分页查看任务、发布脚本版本并切换当前版本、管理任务访问权限、暂停/恢复任务、按状态/关键词筛选和导出 CSV 运行记录、查看管理员操作审计。
- 手机 App：查看任务来源和能力说明、确认接收管理员分发的脚本版本、查看运行状态并停止任务、模拟 OCR 结果。用户可从 Web 向自己的在线设备发起 OCR 远程请求；Android 客户端会在服务端校验后自动批准并启动请求，无需逐项任务审阅或确认，但仍须有有效的 Android 屏幕捕获授权。管理员可分发脚本并查看运行记录，但不能直接启动其他用户设备上的任务。用户可主动开启可见的持续 OCR 待命会话，在会话期间复用已授权的捕获；会话结束后须重新授权。
- 离线演示状态只保存在页面内存中，刷新后恢复为初始演示数据。连接 API 后，用户、设备、脚本和运行记录由本地服务端保存。
- 管理总览和任务页的近 7 天运行数、成功率及运行趋势根据可见运行记录计算；无完成记录时成功率显示为“—”，不显示预设成功率。
- 任务卡的设备数按当前任务所有者/访问权限可用的有效用户设备统计；无需逐设备发布脚本。

## 产品边界

浏览器原型不会运行真实设备操作或 Python 代码。API 使用本地 SQLite 开发存储，上传的脚本由 API 保存并计算 SHA-256，但不会执行；本地服务尚未适配生产 PostgreSQL/S3。演示中的 OCR 结果和运行记录仍是模拟流程。Android 客户端可实际运行已审阅脚本，但仍受 Android 系统授权与可见前台执行限制。

运行状态逻辑的单元测试可通过 `node --test demo/state.test.mjs` 执行。
