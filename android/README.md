# FlowPilot Android 客户端

原生 Kotlin/Jetpack Compose 客户端可登录普通用户账号、绑定设备、同步任务版本、检查脚本 SHA-256、查看完整脚本后再明确确认运行，并显示带脚本版本和开始时间的最近运行结果、本地日志及最近 10 条服务端运行历史。Python 3.12 由 Chaquopy 在 App 进程内运行。演示后端仍只负责账号、授权、脚本分发和运行记录，不会执行 Python。
客户端按服务地址、账号、设备和任务隔离保存最近两个成功校验的脚本版本；新版本无法下载或校验时，可审阅并运行最近一次成功校验的旧版本（远程请求始终严格匹配其指定版本）。用户可解绑本机设备；任务执行期间禁止解绑。缓存不是沙箱或安全保证，运行仍需服务端授权和 Android 系统权限。

客户端使用与 Web demo 一致的浅灰底色、FlowPilot 紫色强调色、渐变欢迎横幅和白色圆角卡片。
设备在线、运行成功、执行中、离线和结束状态使用与 demo 对应的语义状态徽标，便于快速区分当前状态。
任务卡突出任务图标与发布版本；远程待命和无障碍授权状态也会以徽标显示。
管理员分发脚本到指定设备后，Android 会先展示脚本名称、版本、发布者、更新说明和能力范围；设备用户明确确认接收前，不能同步或下载该版本。接收后客户端校验 SHA-256 并缓存。用户只能从 Web 向自己名下的设备发起远程运行；管理员可以分发脚本和查看运行记录，但不能直接启动其他用户设备上的任务。远程运行请求在服务端校验通过后由设备自动批准并启动，不需要逐次任务确认；请求卡显示脚本版本、来源、发起人、有效期和声明能力。服务端仍校验账号、设备、已确认的脚本版本和请求有效期。

## 构建

- Android Studio（Android Gradle Plugin 8.7.3）
- JDK 17 或更新版本
- Android SDK Platform 35 和 Build Tools 35

Debug 构建为了可信局域网内的演示服务显式允许 HTTP；Release 构建默认禁止明文流量，应配置 HTTPS API 地址。不要把 Debug APK 用于正式分发或连接不可信网络。

在 Android Studio 中打开 `android/`，或执行：

```bash
cd android
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。当前配置为私有 APK，支持 `arm64-v8a` 真机和 `x86_64` 模拟器。
连接已启用 USB 或无线调试的设备后，可运行 `./gradlew :app:connectedDebugAndroidTest` 验证 Python 桥接及设备端 OCR；OCR 使用本地生成的测试图，不需要开启无障碍或屏幕捕获权限。

## 首次使用

1. 启动仓库的演示服务：`make dev`。模拟器 API 地址为 `http://10.0.2.2:8001`；当前真机测试默认 API 地址为 `http://192.168.0.101:8001`。手机与开发机需连接同一可信任局域网；开发机 IP 变化时可在登录页修改地址。该服务无 TLS，不要暴露到公网。
2. 使用普通用户账号登录并绑定设备。管理员账号只能用于 Web 管理后台。
   登录页默认勾选“记住登录信息”，API 地址、邮箱和密码会保存在 Android 加密偏好设置中，方便下次测试；取消勾选会清除已保存的登录信息。登录令牌仍单独加密保存，退出登录后账号信息保留以便再次登录。
3. 登录后 App 会显示权限设置引导，列出通知、无障碍、远程待命和屏幕捕获的状态与用途。点击“一键授权并开启待命”后，App 按顺序请求通知、打开无障碍设置并请求屏幕捕获；用户须逐项在 Android 系统界面确认。完成后 App 会开启远程运行待命和持续 OCR，并显示持续通知；可随时从各功能卡片分别停止。拒绝或跳过任何系统授权都会中止引导，不会绕过系统限制。引导关闭后会记住此服务器账号的完成状态，之后仍可从 App 的授权与待命设置卡重新发起。
4. 演示账号默认分配了“抖音订单状态 OCR 演示”任务 `v1.7.0`。可先在 App 中查看发布来源、声明能力、脚本内容和 SHA-256；识别到的状态只显示在设备本地，不点击、不上传 OCR 内容，审阅脚本不需要启用无障碍服务。
5. 管理员将版本分发到设备后，先在“待确认的脚本发布”中核对来源、版本说明和声明能力，再点击“确认接收脚本”；未经确认的版本不会提供下载。首次运行前，在 Android 系统设置中手动启用 **FlowPilot 自动化操作** 无障碍服务。服务仅允许访问抖音 `com.ss.android.ugc.aweme` 或抖音极速版 `com.ss.android.ugc.aweme.lite`，且最多点击每次运行指定的一处可点击文字。若两者都安装，优先打开抖音主版。检查脚本后，再勾选确认运行。
6. 若希望连续接收远程 OCR，可在 App 中主动开启“持续 OCR 待命”。Android 会显示屏幕捕获系统授权；同意后 FlowPilot 以独立前台服务维持该捕获会话，并显示持续通知及停止按钮。待命期间，所有远程 OCR 任务可复用当前会话，不必每个任务都再次弹系统授权。退出待命、系统回收进程/投屏、重启设备或 Android 撤销共享后，会话结束，下次 OCR 需重新授权。此授权不能登录时预先授予、跨会话保存或永久保活。没有开启持续待命时，单次 OCR 仍在任务开始时由 Android 系统弹出授权。任务运行期间 OCR 文本保留在设备本地；上报到演示 API 的运行摘要仅包含通用状态。
7. App 前台每 15 秒发送一次设备心跳并刷新远程请求；进入后台后停止前台轮询。如需接收远程请求，在 App 中开启“远程运行待命”并保留 Android 要求显示的持续服务通知。待命服务每 15 秒发送设备心跳并轮询一次。设备超过 2 分钟没有心跳会在后台显示为离线，离线设备不会接受新的远程运行请求。登录、返回 App 前台或手动点击“同步”时会同步待确认脚本发布及已确认的可用版本。所有远程请求在服务端鉴权和设备空闲检查通过后由客户端自动批准并启动，无需逐任务审阅、确认或配置预授权；任务仍可在设备上停止。请求所需的无障碍能力必须已在 Android 设置中启用；屏幕捕获能力仍须由 Android 系统授权。App 前台收到 OCR 请求时会弹出 Android 屏幕捕获授权（若尚无有效持续 OCR 会话）；后台收到时会通知用户打开 App 完成系统授权。持续 OCR 会话结束或被系统回收后需要重新授权。

## Python 桥接接口

脚本在全局变量 `bridge` 上可用以下方法：

- `bridge.open_douyin()`：打开已安装的抖音；若已在抖音前台则不重复启动。
- `bridge.wait_for_douyin(timeout_seconds=15)`：等待抖音主版/极速版进入前台，超时范围为 1–30 秒；用于避免启动动画或系统切换期间过早截图，用户停止任务时会尽快结束等待。
- `bridge.ocr()`：OCR 当前屏幕并返回识别文本；仅在抖音处于前台时允许。
- `bridge.click_text(text)`：按无障碍节点文字执行一次点击；每次任务最多一次，且只能作用于抖音主版或极速版。
- `bridge.log(message)`：将最多 4 KB 的当前运行日志保留在本机；开始新运行时清空上一运行的日志。
- `bridge.is_stopped()`：查询用户是否已请求停止。脚本应在循环中检查该值，并及时退出。

最小脚本示例见 [`examples/open_douyin.py`](examples/open_douyin.py)。若任务名称包含“抖音”，客户端会在执行前启动抖音；脚本仍应调用 `bridge.open_douyin()`，以便在远程恢复或 App 切换场景下确保目标应用已打开。

## 权限和安全边界

- Android 不允许 App 静默授予 MediaProjection 屏幕捕获权限，也不允许 App 代替用户启用无障碍服务；本客户端不会绕过这些系统限制。远程任务在服务端校验后自动运行，不需要逐任务审阅或确认；但 OCR/屏幕捕获仍须通过 Android 系统授权，未启用的无障碍能力仍须由用户在系统设置中启用。系统拒绝授权则不执行。本地运行同样遵循正常系统授权流程。持续 OCR 是用户主动开启的单次可见会话，不是永久权限或后台静默保活。
- 通知运行时权限和无障碍设置由登录后的权限引导集中说明；引导不会暗中启动待命。远程待命是可选的，运行期间必须保留用户可见的前台服务通知。
- Python 脚本在 App 进程内运行，**不是安全沙箱**。运行确认和 SHA-256 仅帮助用户审阅代码/检测下载内容变化，不隔离恶意脚本。只运行你信任并检查过的代码。
- 当前 OCR 使用设备端 ML Kit；截图和 OCR 文本不上传。用户脚本本身具有 App 进程权限，可能访问 App 可访问的数据或网络。
- 演示 API 默认使用无 TLS HTTP 和演示账号。不要在不可信网络、生产账号或公网部署中使用。
- 目前只面向中国版抖音和抖音极速版，不包含无障碍手势、多次点击或其他应用自动化。
