# FlowPilot Android 客户端

原生 Kotlin/Jetpack Compose 客户端可登录普通用户账号、绑定设备、同步任务版本、检查脚本 SHA-256、查看完整脚本后再明确确认运行，并显示带脚本版本和开始时间的最近运行结果、本地日志及最近 10 条服务端运行历史。Python 3.12 由 Chaquopy 在 App 进程内运行。演示后端仍只负责账号、授权、脚本分发和运行记录，不会执行 Python。
客户端按服务地址、账号、设备和任务隔离保存最近两个成功校验的脚本版本；新版本无法下载或校验时，可审阅并运行最近一次成功校验的旧版本（远程请求始终严格匹配其指定版本）。用户可在 App 查看并撤销有效远程预授权，也可解绑本机设备；任务执行期间禁止解绑。缓存不是沙箱或安全保证，运行仍需服务端授权和 Android 系统权限。

客户端使用与 Web demo 一致的浅灰底色、FlowPilot 紫色强调色、渐变欢迎横幅和白色圆角卡片。
设备在线、运行成功、执行中、离线和结束状态使用与 demo 对应的语义状态徽标，便于快速区分当前状态。
任务卡突出任务图标与发布版本；远程待命和无障碍授权状态也会以徽标显示。
远程运行请求卡会显示待确认/已授权状态、脚本版本、来源、发起人、请求截止时间和声明能力，方便确认授权范围与有效期。预授权列表会标明授权起始版本及后续版本范围。

## 构建

- Android Studio（Android Gradle Plugin 8.7.3）
- JDK 17 或更新版本
- Android SDK Platform 35 和 Build Tools 35

在 Android Studio 中打开 `android/`，或执行：

```bash
cd android
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。当前配置为私有 APK，支持 `arm64-v8a` 真机和 `x86_64` 模拟器。
连接已启用 USB 或无线调试的设备后，可运行 `./gradlew :app:connectedDebugAndroidTest` 验证 Python 桥接及设备端 OCR；OCR 使用本地生成的测试图，不需要开启无障碍或屏幕捕获权限。

## 首次使用

1. 启动仓库的演示服务：`make dev`。模拟器 API 地址为 `http://10.0.2.2:8001`；当前真机测试默认 API 地址为 `http://192.168.0.101:8001`。手机与开发机需连接同一可信任局域网；开发机 IP 变化时可在登录页修改地址。该服务无 TLS，不要暴露到公网。
2. 使用普通用户账号登录并绑定设备。管理员账号只能用于 Web 管理后台。
   登录页默认勾选“记住登录信息”，API 地址、邮箱和密码会保存在 Android 加密偏好设置中，方便下次测试；取消勾选会清除已保存的登录信息。登录令牌仍单独加密保存，退出登录后账号信息保留以便再次登录。
3. 登录后 App 会显示权限设置引导，列出通知、无障碍、远程待命和屏幕捕获的状态与用途。通知可在 App 内请求；无障碍服务需由用户从引导跳转 Android 设置并手动启用。引导可以稍后关闭，之后可从相应功能卡片继续设置。
4. 演示账号默认分配了“抖音订单状态 OCR 演示”任务 `v1.7.0`。可先在 App 中查看发布来源、声明能力、脚本内容和 SHA-256；识别到的状态只显示在设备本地，不点击、不上传 OCR 内容，审阅脚本不需要启用无障碍服务。
5. 首次运行前，在 Android 系统设置中手动启用 **FlowPilot 自动化操作** 无障碍服务。服务仅允许访问抖音 `com.ss.android.ugc.aweme` 或抖音极速版 `com.ss.android.ugc.aweme.lite`，且最多点击每次运行指定的一处可点击文字。若两者都安装，优先打开抖音主版。检查脚本后，再勾选确认运行。
6. 本地运行屏幕捕获/OCR 任务时，Android 系统会弹出屏幕捕获授权对话框。该授权与具体捕获会话绑定，只能在实际 OCR 运行时由 Android 系统逐次授予，不能登录时预先授予、保存或永久保活。App 会启动前台运行服务并显示可停止的通知；任务执行期间服务每分钟发送设备心跳，任务结束后停止。运行期间 OCR 文本保留在设备本地；上报到演示 API 的运行摘要仅包含通用状态。
7. App 前台每 15 秒发送一次设备心跳并刷新远程请求；进入后台后停止前台轮询。如需接收远程请求，在 App 中开启“远程运行待命”并保留 Android 要求显示的持续服务通知。待命服务每 15 秒发送设备心跳并轮询一次。设备超过 2 分钟没有心跳会在后台显示为离线，离线设备不会接受新的远程运行请求。不需要逐次 Android 系统授权的首次远程任务需用户检查脚本并确认，也可同时授权此任务、此设备及后续版本 30 天；符合授权范围的后续任务会自动在可见前台服务运行。远程 OCR 请求不会发单独的请求通知；App 前台同步到请求后会自动弹出审阅对话框，用户确认后 Android 每次仍会显示屏幕捕获系统授权弹窗，授权后才运行。App 在后台时请求保持待处理，用户打开 App 后弹窗；系统拒绝授权则本次运行失败，预授权不能代替系统授权。

## Python 桥接接口

脚本在全局变量 `bridge` 上可用以下方法：

- `bridge.open_douyin()`：打开已安装的抖音；若已在抖音前台则不重复启动。
- `bridge.wait_for_douyin(timeout_seconds=15)`：等待抖音主版/极速版进入前台，超时范围为 1–30 秒；用于避免启动动画或系统切换期间过早截图，用户停止任务时会尽快结束等待。
- `bridge.ocr()`：OCR 当前屏幕并返回识别文本；仅在抖音处于前台时允许。
- `bridge.click_text(text)`：按无障碍节点文字执行一次点击；每次任务最多一次，且只能作用于抖音主版或极速版。
- `bridge.log(message)`：将最多 4 KB 的当前运行日志保留在本机；开始新运行时清空上一运行的日志。
- `bridge.is_stopped()`：查询用户是否已请求停止。脚本应在循环中检查该值，并及时退出。

最小脚本示例见 [`examples/open_douyin.py`](examples/open_douyin.py)。若任务名称包含“抖音”，客户端会在执行前启动抖音；脚本仍应调用 `bridge.open_douyin()`，以便在远程恢复或 App 切换场景下确保目标应用已打开。

## 权限和安全边界

- Android 不允许 App 静默授予 MediaProjection 屏幕捕获权限，也不允许 App 代替用户启用无障碍服务；本客户端不会绕过这些系统限制。远程 OCR 请求在 App 前台时弹出审阅对话框，用户确认后逐次通过 Android 系统授权；App 在后台时不发请求通知，请求留待用户打开 App 后弹窗。系统拒绝授权则不执行。本地运行同样遵循正常系统授权流程。
- 通知运行时权限和无障碍设置由登录后的权限引导集中说明；引导不会暗中启动待命。远程待命是可选的，运行期间必须保留用户可见的前台服务通知。
- Python 脚本在 App 进程内运行，**不是安全沙箱**。运行确认和 SHA-256 仅帮助用户审阅代码/检测下载内容变化，不隔离恶意脚本。只运行你信任并检查过的代码。
- 当前 OCR 使用设备端 ML Kit；截图和 OCR 文本不上传。用户脚本本身具有 App 进程权限，可能访问 App 可访问的数据或网络。
- 演示 API 默认使用无 TLS HTTP 和演示账号。不要在不可信网络、生产账号或公网部署中使用。
- 目前只面向中国版抖音和抖音极速版，不包含无障碍手势、多次点击或其他应用自动化。
